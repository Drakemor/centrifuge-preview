# Centrifuge model preview

Interactive Three.js viewer with a midplane section cut and stack preview.

Open [the live page](https://drakemor.github.io/centrifuge-preview/).

Current release: **0.1.0**

Use the **Version** dropdown to switch between semver STL exports (0.1.0, 0.0.3, 0.0.2, 0.0.1).
